# XxMauro's Launcher

Launcher desktop moderno per la community **XxMauro**, con supporto a:
- **Minecraft** (account Microsoft o modalità offline/craccata)
- **Roblox** (login obbligatorio)

L'obiettivo è offrire un unico client da cui avviare giochi, server ed esperienze community, con una UI fluida in stile Lunar Client.

## Visione del progetto

### 1) Doppia modalità: Minecraft / Roblox
- Switch rapido con un pulsante nella UI.
- Transizione visiva tra le modalità (cambio palette, animazioni "flip", micro-effetti fluidi).
- Stato e preferenze separati per ogni modalità.

### 2) Esperienza Minecraft personalizzata
- Avvio Minecraft con interfaccia personalizzata del launcher.
- Sezione profili (vanilla/modded).
- Avvio diretto dei server della community.
- Supporto login Microsoft e profilo offline.

### 3) Esperienza Roblox personalizzata
- Tema launcher dedicato Roblox.
- Login account Roblox nel client.
- Funzioni social: visualizzare/amici online e join rapido.
- Lista giochi preferiti fissabili in homepage.
- Pulsante **Play** grande e centrale.

### 4) Design UI/UX
- Stile moderno, minimal, arrotondato.
- Layout pulito con card e gerarchia visiva chiara.
- Performance fluida (animazioni leggere, feedback immediato).
- Ispirazione: Lunar Client, ma con identità propria della community.

## MVP proposto
1. Shell app desktop (finestra principale + routing UI).
2. Toggle Roblox/Minecraft con cambio tema.
3. Blocchi homepage: account, preferiti, server/giochi.
4. Pulsante Play per la modalità attiva.
5. Persistenza locale impostazioni utente.

## Roadmap (bozza)
- **Fase 1:** UI base + theming + mock login.
- **Fase 2:** integrazione account reali (Roblox/Microsoft).
- **Fase 3:** integrazione avvio Minecraft profili/server.
- **Fase 4:** funzionalità social Roblox + preferiti avanzati.
- **Fase 5:** polishing UX, updater automatico, telemetria minima.

## Principi guida
- Community-first: tutto parte dalle esigenze dei tuoi utenti.
- Semplicità: pochi click per arrivare al gioco/server.
- Coerenza: stessa qualità UX in entrambe le modalità.
- Estendibilità: architettura pronta per nuove feature future.
